## ::streamline-ultimate-color:copy-paste-1::Project Overview

==EuoraCraft Launcher== (ECL) is an **open-source third-party launcher** for Minecraft. It manages game accounts, multiple game instances, and their community content, while providing multiplayer and plugin-extension capabilities.

Current public releases primarily target Windows. Download installers from [GitHub Releases](https://github.com/ECLTeam/EuoraCraft-Launcher/releases), and read the documentation before getting started.

## What can you do with ECL?

| Feature | Description |
|:---|:---|
| Accounts and appearance | Supports Microsoft, Yggdrasil, and offline accounts, with skin- and cape-related management. |
| Game instances | Create and maintain separate instances for different versions, mod sets, or play styles. |
| Game content | Manage mods, resource packs, saves, servers, and screenshots in each instance, with import, export, validation, and repair tools. |
| Community resources | Browse, download, and manage game and community resources provided by third-party platforms. Check the source and license before using them. |
| Multiplayer rooms | Uses EasyTier to provide multiplayer rooms and virtual-network capabilities. Connection quality depends on the network and relevant third-party services. |
| Launcher extensions | Plugins can extend account authentication, launch workflows, multiplayer protocols, crash analysis, and UI features. |
| Diagnostics and updates | Provides update checks, automatic updates on supported channels, and local logs and crash-report tools. |

## Usage notes

::: warning Third-party services
Microsoft/Mojang sign-in, game downloads, mirrors, mod platforms, community resources, and multiplayer services are provided by their respective third parties. When using them, also comply with their terms of service, privacy policies, and licenses.
:::

::: caution Third-party plugins
Plugins can add capabilities to the launcher, but may also request additional permissions or access local resources. Install plugins only from trusted sources, and review their description and permission declarations before installing them.
:::
