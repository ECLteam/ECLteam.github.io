## Project Overview

Welcome to the developer documentation for ==EuoraCraft Launcher==. This open-source Minecraft launcher aims to offer a better gameplay experience and more customization options. Whether you want to contribute code, fix bugs, or add features, this is where to begin.

The project is a cross-platform desktop application built primarily with `PyTauri` and `Vue 3`, supporting Windows, Linux, and macOS. We welcome developers interested in Minecraft launchers to join the community and help improve the experience.

For general Minecraft-launcher principles, see the [technical tutorials](/en/tutorials/minecraft-launcher/). This section focuses on developing and contributing to EuoraCraft Launcher itself.
