# Learning to Build a Minecraft Launcher

This tutorial explains the main ideas behind building a Minecraft launcher.

::: tip Prerequisites
Before starting, you should:

1. Know at least one programming language, such as Python.
2. Use a language that supports I/O operations and parsing data formats such as JSON.
3. Have basic programming ability for reading and writing code.
4. Be comfortable reading technical material.
:::
