## ::streamline-ultimate-color:copy-paste-1::项目介绍

==EuoraCraft Launcher==（ECL）是一个面向 Minecraft 的**第三方开源启动器**。它用于管理游戏账户、多个游戏实例及其社区资源，并提供联机与插件扩展能力。

当前公开发布版本主要面向 Windows。请从 [GitHub Releases](https://github.com/ECLTeam/EuoraCraft-Launcher/releases) 获取安装包，并优先阅读本网站后续的使用说明。

## 你可以用 ECL 做什么？

| 功能 | 说明 |
|:---|:---|
| 管理账户与外观 | 支持 Microsoft、Yggdrasil 和离线账户，并提供皮肤、披风相关管理功能。 |
| 管理游戏实例 | 可为不同版本、模组组合或游玩用途分别建立和维护独立实例。 |
| 整理游戏内容 | 在实例中管理模组、资源包、存档、服务器、截图等内容，并提供导入、导出、检查与修复等工具。 |
| 获取社区资源 | 可浏览、下载和管理由第三方平台提供的游戏与社区资源。使用前请确认资源来源和许可证。 |
| 创建联机房间 | 基于 EasyTier 提供联机房间与虚拟网络能力；实际连接质量取决于网络环境和相关第三方服务。 |
| 扩展启动器 | 支持插件扩展账户认证、启动流程、联机协议、崩溃分析和界面功能等能力。 |
| 诊断与更新 | 提供更新检查、受支持渠道下的自动更新，以及本地日志和崩溃报告工具。 |

## 使用提示

::: warning 第三方服务
Microsoft/Mojang 登录、游戏下载、镜像源、模组平台、社区资源和联机服务均由相应第三方提供。使用这些功能时，请同时遵守其服务条款、隐私政策和许可证。
:::

::: caution 第三方插件
插件可以为启动器增加功能，也意味着其可能请求额外权限或访问本地资源。请仅从可信来源安装插件，并在安装前查看其说明与权限声明。
:::
